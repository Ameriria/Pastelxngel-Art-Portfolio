## About the project

This repository contains my official personal art portal and portfolio as **pastelxngel**. This project was designed and developed to showcase the synergy between my creative work as a digital illustrator and my technical skills as a **Front-End Developer**.

Unlike template-based sites, this application was built from scratch using **Vanilla JavaScript** and **Custom CSS** to ensure a lightweight, high-performance experience that perfectly captures a "soft-pastel" coquette aesthetic. It features a dynamic gallery, a commission price list, and a real-time order tracking system (Kanban) integrated with **Supabase**.

### Key Features:

- **Dynamic Content:** Real-time data fetching for the gallery, pricing, and order status via Supabase.
- **Responsive Architecture:** Custom layouts designed for all devices, including a specialized mobile view where the profile acts as a footer to prioritize content.
- **Bilingual Support:** Fully integrated English and Spanish interface.
- **Optimized UI:** Custom glassmorphism effects and a collapsible "Bio" section for better mobile UX.

## Sobre el proyecto

Este repositorio contiene mi portal y portafolio de arte personal oficial como **pastelxngel**. El proyecto fue diseñado y desarrollado para demostrar la sinergia entre mi trabajo creativo como ilustradora digital y mis habilidades técnicas como **Desarrolladora Front-End**.

A diferencia de sitios basados en plantillas, esta aplicación fue construida desde cero utilizando **JavaScript Vanilla** y **CSS personalizado** para garantizar una experiencia ligera y de alto rendimiento que captura perfectamente una estética "soft-pastel" y coquette. Incluye una galería dinámica, lista de precios y un sistema de seguimiento de pedidos en tiempo real (Kanban) integrado con **Supabase**.

### Características Principales:

- **Contenido Dinámico:** Carga de datos en tiempo real para la galería, precios y estado de pedidos mediante Supabase.
- **Arquitectura Responsiva:** Diseños personalizados para todos los dispositivos, incluyendo una vista móvil especializada donde el perfil actúa como footer para priorizar el arte.
- **Soporte Bilingüe:** Interfaz completa en inglés y español.
- **UI Optimizada:** Efectos de glassmorphism y sección de biografía retráctil para mejorar la experiencia en celulares.
